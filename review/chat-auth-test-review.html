Implementation evidence

The initial GLM regression reproduced addressable=true with an erroneous logged-out status. The shared backend parser now supplies both consumers. Browser auth-response interpretation was removed; existing server-owned recovery UI is used. Provider recovery endpoints and error triggers honor provider scope.

The CLI parser requires a successful explicit login response, or explicit logout; unknown output leaves state unchanged. The positive response prefix and process exit behavior were checked against Codex's login command implementation.

No dashboard CSS or markup was added or modified. The referenced dashboard-style-check skill is absent from this checkout; the existing recovery banner is reused.
