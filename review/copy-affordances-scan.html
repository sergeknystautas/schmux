Each site

1. Chat user bubble

reference pattern

The button sits at position: absolute in the corner of .bubble. Its opacity is 0 until :hover or :focus-within, and @media (hover: none) keeps it visible on touch screens. It uses copyToClipboard() from lib/utils.ts, toasts "Copied message" or "Failed to copy", and is hidden when the message is image-only. The CSS lives in chat.module.css:94–114, which means only the chat code can use it.

5. Terminal selection mode

not a fit

"Copy N lines" is the main action of a mode: it copies, then exits selection mode. There's no block to hover over, because the selection lives in xterm.js. This should stay a toolbar button.

Duplication found along the way

  • The same copy SVG is pasted inline in 4 files: UserMessageBubble, SessionSidebar, DiffPage, and SessionDetailPage.
  • The "copyToClipboard, then toast success or failure" sequence is written by hand in 4 places: UserMessageBubble, useSessionActions, DiffPage, and SessionDetailPage. LogsPage skips the helper entirely.
  • The hover-reveal CSS is scoped to chat.module.css, so nothing outside chat can reuse it as it stands.
